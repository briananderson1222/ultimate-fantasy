# Installation and Setup Guide

## System Requirements

### iOS Requirements
- **iOS Version**: 14.0 or later
- **Device Compatibility**: iPhone 7 or newer, iPad Air 2 or newer
- **Storage**: 250 MB free space required
- **Internet**: WiFi or cellular data connection
- **Optional**: Face ID, Touch ID for biometric login

### Android Requirements
- **Android Version**: 8.0 (API level 26) or later
- **RAM**: 3GB minimum, 4GB recommended
- **Storage**: 300 MB free space required
- **Internet**: WiFi or cellular data connection
- **Optional**: Fingerprint sensor for biometric login

## Download and Installation

### iOS Installation

1. **Open App Store**: Tap the App Store icon on your iPhone or iPad
2. **Search**: Type "Ultimate Fantasy" in the search bar
3. **Select App**: Look for the Ultimate Fantasy app with our official logo
4. **Download**: Tap "Get" button (app is free)
5. **Install**: Wait for download and automatic installation
6. **Open**: Tap "Open" or find the app icon on your home screen

**Alternative Installation Methods:**
- **QR Code**: Scan the QR code from our website
- **Direct Link**: Tap App Store link from email or website
- **Family Sharing**: Download from family member's purchases

### Android Installation

1. **Open Google Play Store**: Tap the Play Store icon
2. **Search**: Type "Ultimate Fantasy" in the search bar
3. **Select App**: Choose the official Ultimate Fantasy app
4. **Install**: Tap "Install" button
5. **Permissions**: Grant requested permissions when prompted
6. **Open**: Tap "Open" or find app in your app drawer

**Alternative Installation Methods:**
- **APK Sideload**: Available for enterprise/beta testing only
- **Samsung Galaxy Store**: Also available on Samsung devices
- **Amazon Appstore**: For Fire tablets and phones

## Initial Setup

### First Launch

When you first open the app, you'll see the welcome screen with these options:

1. **Create Account**: For new users
2. **Sign In**: For existing users
3. **Guest Mode**: Limited functionality for browsing (no account required)

### Creating Your Account

**Step 1: Basic Information**
- **Email Address**: Must be valid and accessible
- **Username**: 3-30 characters, letters, numbers, underscores only
- **Password**: Minimum 8 characters with uppercase, lowercase, and number
- **Confirm Password**: Must match exactly

**Step 2: Personal Details**
- **First Name**: Your given name
- **Last Name**: Your family name
- **Date of Birth**: Used for age verification (13+ required)
- **Timezone**: Automatically detected, but can be changed

**Step 3: Preferences**
- **Favorite Sports**: Select your preferred sports for personalized content
- **Notification Preferences**: Choose what alerts you want to receive
- **Privacy Settings**: Control what information is visible to other users

**Step 4: Email Verification**
1. Check your email for verification message
2. Tap the verification link
3. Return to the app to continue

### Setting Up Biometric Login (Optional)

**iOS - Face ID/Touch ID**
1. After account creation, go to **Settings** > **Security**
2. Toggle on **"Enable Face ID"** or **"Enable Touch ID"**
3. Follow prompts to scan your face or fingerprint
4. Test the feature by logging out and back in

**Android - Fingerprint/Face Unlock**
1. Go to **Settings** > **Security** > **Biometric Login**
2. Toggle on **"Enable Fingerprint"** or **"Enable Face Unlock"**
3. Follow system prompts to register biometric data
4. Test by logging out and using biometric login

## App Permissions

### Required Permissions

**iOS Permissions**
- **Internet Access**: Required for all app functionality
- **Background App Refresh**: Needed for real-time updates
- **Notifications**: Essential for timely alerts

**Android Permissions**
- **Internet**: Full network access for API communication
- **Network State**: Check connection status
- **Wake Lock**: Keep device awake during drafts
- **Notifications**: Push notification delivery

### Optional Permissions

**iOS Optional**
- **Location Services**: For local team recommendations
- **Contacts**: To find friends already using the app
- **Camera**: For profile photo capture
- **Photo Library**: For profile photo selection

**Android Optional**
- **Access Fine Location**: Local content and timezone detection
- **Read Contacts**: Find friends using the app
- **Camera**: Take profile photos
- **Read External Storage**: Select existing photos
- **Vibrate**: Haptic feedback for notifications

### Managing Permissions

**iOS Permission Management**
1. Go to **Settings** > **Privacy & Security**
2. Select **Ultimate Fantasy**
3. Toggle permissions on/off as desired
4. Changes take effect immediately

**Android Permission Management**
1. Go to **Settings** > **Apps** > **Ultimate Fantasy**
2. Tap **Permissions**
3. Toggle individual permissions
4. Restart app if prompted

## Account Configuration

**Basic Profile**
1. **Profile Photo**: Upload or take a new photo

**League Activity** (Recommended: ON)
- New trade proposals

**Internet Connection**

**Offline Mode**
- **Cache Duration**: How long to store data offline

- **Image Loading**: WiFi only, Always, or Never

## Troubleshooting Setup Issues

### Common Installation Problems

**"Cannot Download App" (iOS)**
1. Check available storage space (need 250MB+)
2. Ensure iOS 14.0 or later
3. Try downloading over WiFi instead of cellular
4. Restart device and try again
5. Sign out and back into App Store

**"App Not Installing" (Android)**
1. Check available storage (need 300MB+)
2. Verify Android 8.0+ installed
3. Clear Google Play Store cache
4. Check if device is compatible
5. Try installing over WiFi

### Account Creation Issues

**Email Verification Not Received**
1. Check spam/junk folder
2. Verify email address was entered correctly
3. Ensure email provider allows automated emails
4. Try different email address
5. Contact support for manual verification

**Username Already Taken**
1. Try variations with numbers or underscores
2. Use username checker before submitting
3. Consider using middle initial or nickname
4. Add year of birth to desired username

**Password Requirements Not Met**
- Must be at least 8 characters
- Include uppercase letter (A-Z)
- Include lowercase letter (a-z)
- Include number (0-9)
- Cannot contain username or email
- Cannot be common password

### Login Problems

**Forgot Password**
1. Tap "Forgot Password" on login screen
2. Enter email address
3. Check email for reset link
4. Follow instructions to create new password
5. Use new password to log in

**Biometric Login Not Working**
1. Ensure biometric data is registered in device settings
2. Try manual login with password
3. Re-register biometric data in app settings
4. Update to latest app version
5. Contact support if issues persist

### Performance Optimization

**Slow App Performance**
1. Close other running apps
2. Restart device
3. Clear app cache (Android)
4. Update to latest version
5. Free up device storage space

**Connection Issues**
1. Check internet connection stability
2. Switch between WiFi and cellular
3. Restart router/modem if using WiFi
4. Contact ISP if widespread connectivity issues
5. Try different network if available
